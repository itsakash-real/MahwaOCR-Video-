    4. Chapter finished. Repeat for the next chapter.

    Shows every chapter. ok = done. outdated = build that chapter again.

  • QUESTION
    5. Something is wrong with the pictures. What do you want to do?
    • A. Build again (no AI, free)

      Use this after you change the audio, the recap, or the fix file in option C.

      python -m manhwa_ocr video build --chapters 8 --session "manhwa-2"

      Without --force it rebuilds only what changed, so it is much faster.

    • B. AI review (needs a DeepSeek key, see Setup)

      Status: the review loop is built and tested with fake data, but not yet run on a real chapter.

      python -m manhwa_ocr video review --chapter 8 --session "manhwa-2"

      When it says approved, render it:

      python -m manhwa_ocr video render --chapter 8 --session "manhwa-2"
    • C. Fix it by hand
      1. Open ManhwaRecaps\manhwa-2\.work\video\ch8\REVIEW.md, and the storyboard pictures in ManhwaRecaps\manhwa-2\video\.
      2. Write your fixes in ManhwaRecaps\manhwa-2\video\chapter_8.fixes.json. Example:
      { "version": 1, "drop": [ {"panel": "P016-06", "reason": "blank page, no character"} ], "face": [ {"panel": "P017-02", "top": 0.12, "bottom": 0.46} ], "crop": [ {"panel": "P018-05", "shape": "3:4", "box": [0.0, 0.10, 0.6, 0.85]} ] }
      • drop: remove a panel with no character and no story.
      • face: the head's top and bottom, as a fraction of the panel height (0 = top, 1 = bottom).
      • crop: an exact box. shape is 9:16, 3:4, 1:1, 4:3 or 16:9.

      If the file has a mistake, the build names the line and applies none of it. Then go back to A.

  • PROBLEM
    6. Something failed (red text). Find your message.
    The message saysWhat to do
    No narration audioGo to step 1. The file is missing or has the wrong name.
    too short to hold N panelsThe narration is shorter than the pictures need. Record a longer narration.
    whisper or estimatedThe voice could not be matched. Check the audio is clear, and see Setup.
    not valid JSON or Error:Open the file the message names, fix the line it names, then rebuild.
    Anything elseCopy the last 20 lines of the terminal and send them to whoever maintains this tool.

    Never delete files to get past an error.
